# Litematica Material Filter

Аддон для **Litematica**

Позволяет фильтровать список материалов по запросу и выводить в **Панель информации** или в Голограмму схемы в мире
только нужные блоки - без ручного нажатия «Игнорировать» на каждый лишний материал.

## Использование

1. Загрузи схему в Litematica, дальше выбери **`Список материалов`**, и там будет кнопка **`Открыть Фильтр`** или просто кнопка **`N`** по умолчанию. Последняя активная схема загружается автоматически.
2. В окне **Фильтр материалов**:
    - Вкладки **`HUD`** / **`Голограмма`** / **`Оба`** — для какого списка сейчас выбираешь блоки. Рядом — сколько блоков отмечено.
    - **Клик** по строке выбирает блок, **зажать и провести** — выбрать несколько подряд.
    - Поиск (`стекло`, `oak`, `редст`…) по русскому названию и по ID; **`Enter`** или **`Выбрать найденные`** отмечает всё найденное.
    - **`Не построенное`** — отметить блоки, которых ещё нет в мире; **`↻`** — пересчитать по миру; **`Только выбранные`** — показать только отмеченное; **`Сбросить фильтр`** — очистить текущую вкладку.
    - Цвет числа «Всего»: **жёлтый** — нужно собрать, **зелёный** — уже собрано (хватает в инвентаре, включая шалкеры), **красный** — уже стоит в мире.
3. Колонка настроек справа:
    - **Выбранные блоки: Показывать / Скрывать** — белый или чёрный список.
    - **Панель HUD**: Список материалов, Сырьё для крафта (дерево рецептов в списке и в HUD; ползунок «Ступень раскрафта» под тумблером задаёт, до какой ступени его раскрывать), Только сырьё (список вкладки HUD и сам HUD показывают исходные ресурсы; ползунок «Ступень раскрафта» под этим тумблером задаёт, до какой ступени разбирать; сырьё считается для блоков, выбранных в обычном списке, а в списке сырья отмечаются ресурсы, которые показывать в HUD; если ничего не отмечено — показываются все), Скрывать собранное. Блок другого типа на месте схемы не считается поставленным.
    - **Голограмма**: Применять фильтр, Сущности и жидкости.
4. HUD-панель в правом нижнем углу показывает только то, что ещё нужно собрать (всего / стаки / шалкеры). Страницы листаются клавишами **`Page Up`** / **`Page Down`** (переназначаются в настройках управления).
